КАК УВИДЕТЬ ЗАПАХ — WEB/PWA-РЕДАКЦИЯ 1.0
Дата сборки: 25.08.2026

ЧТО ЭТО
Это веб-версия утвержденной автономной галереи. Содержание и визуальный масштаб экспонатов не изменялись. Тяжелый единый HTML разделен на быстрый титульный index.html и 10 самостоятельных залов. Каждый зал загружается только при открытии.

ФАЙЛЫ
index.html — главная страница и каталог залов
halls/ — 10 залов, каждый самодостаточный HTML с изображениями
manifest.webmanifest — описание PWA
service-worker.js — кэширование просмотренных страниц для ускорения повторного открытия
icons/ — иконки приложения
offline.html — страница при отсутствии сети
error.html — страница ошибки для хостинга

ВАЖНО
PWA работает только через HTTPS (или localhost для тестирования). Не открывайте index.html двойным щелчком и не оценивайте PWA через file:// — в таком режиме service worker не запускается.

ПРИНЦИП КЭШИРОВАНИЯ
При установке кэшируется только оболочка сайта. Залы кэшируются по мере посещения, поэтому первый запуск остается легким и не требует скачивать всю галерею сразу.
