РАЗМЕЩЕНИЕ В YANDEX CLOUD OBJECT STORAGE — КОРОТКАЯ ИНСТРУКЦИЯ

1. Войдите в Yandex Cloud и создайте платежный аккаунт/облако, если их еще нет.
2. Откройте Object Storage -> Создать бакет.
3. Для первой публичной ссылки используйте уникальное имя БЕЗ ТОЧЕК, например:
   kak-uvidet-zapah-kuchmenko
   (если занято, добавьте год или короткое слово).
   Имя без точек важно: технический адрес такого бакета поддерживает HTTPS без отдельного сертификата.
4. Для чтения объектов установите публичный доступ «Для всех».
5. Загрузите ВСЕ содержимое этой папки с сохранением структуры:
   index.html
   error.html
   offline.html
   manifest.webmanifest
   service-worker.js
   папку halls
   папку icons
6. В настройках бакета откройте вкладку «Веб-сайт» / Website -> Hosting.
7. Главная страница: index.html
   Страница ошибки: error.html
8. Сохраните настройки.
9. Откройте HTTPS-адрес сайта. Для бакета без точек работают технические адреса вида:
   https://<имя-бакета>.website.yandexcloud.net
   или https://website.yandexcloud.net/<имя-бакета>/
10. Проверьте на телефоне:
   - титульную страницу;
   - светлую/темную тему;
   - открытие залов 1, 3, 8 и 10;
   - после этого все 10 залов;
   - «Добавить на главный экран» / установка PWA.

ПОЗЖЕ ДЛЯ КОНКУРСА
Можно подключить собственный домен и HTTPS-сертификат. Тогда в паспорт проекта и конкурсные материалы вносится постоянный красивый URL и QR-код.
